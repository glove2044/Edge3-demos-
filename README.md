# EDGE3 — Athlete Investment Intelligence

Public-facing hosted demo site for EDGE3.net.

EDGE3 is positioned as organizational intelligence and decision infrastructure
for modern athletic departments — not a recruiting platform. The site is built
around the operating model (strategic objective → critical decision → capability
gap → configured intelligence → execution → business impact → continuous
learning), the athlete lifecycle, and Chief of Staff capabilities for head
coaches and front offices.

## Pages

- `index.html` — Home: hero, core thesis, strategic objectives, operating model, Chief of Staff, athlete lifecycle, capability-to-financial-outcome mapping, technology positioning, executive briefing CTA
- `enterprise.html` — Enterprise Partnerships: sports as the proving ground for enterprise capability (demonstrate → validate → commercialize)
- `demonstrations.html` — Executive case studies following the fixed structure: strategic objective, critical decision, capability gap, configured solution, business value, transferable learning
- `styles.css` — Shared design system (monochrome executive palette, single accent)

Static HTML/CSS — no build step. Serve the directory with any static host
(GitHub Pages compatible).
